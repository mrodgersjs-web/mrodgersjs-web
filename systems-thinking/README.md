# Systems Thinking

Everything built in Orca for systems thinking, plus the `/systemsthinking` metaskill.

- `studio/` — Systems Thinking Studio: `studio` CLI, 8-phase contract, archetypes (Kim), Meadows leverage points, Cynefin contexts, Euler stock-flow models, process maps, diagrams, ProofPacket, knowledge library.
- `workspace/` — the Orca Systems-Thinking workspace: 1000X plan, gap reports, Jake run, campaigns, Recall corpus (853 tagged cards), proofs, Recall pipeline scripts.
- `skills/` — `/systemsthinking` meta + 65 step skills across 12 stages (Intake, Frame, Diagnose, Leverage, Ground, Polymath, Synthesize, Verify, Loops, KPIs, Goals, Operate). Regenerate with `python3 gen_skills.py skills`.
- Jev: every typed judgment follows the jev-everywhere ladder (CODE → JEV → SYSTEM 2 → HUMAN); the 8 phases are wrapped as a jevharness switch domain.
