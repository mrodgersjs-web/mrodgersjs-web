## Closed-loop work (dumb loops that ship)

- A **Ralph loop** is a while-loop around a prompt: do the thing → model claims done → send it back to do the thing again so it reviews its own work and catches what it missed. Origin: Ralph Wiggum (Simpsons) — try the same thing until it works. Dumbest form is a scripted loop; next form is Claude Code’s `loop` command. Sessions last ~3 days and need refresh. Point the loop at a *pile of work*, not one ticket. [Card: Ralph Loops: Build Dumb AI Loops That Ship — Chris Parsons, Cherrypick](https://www.youtube.com/watch?v=2TLXsxkz0zI)
- Teams that add Ralph-class loops **without fixing the constraint go slower**. If you ship 200 PRs into a once-a-month release instead of 20, coding speed is not the bottleneck — review/release is. Always fix the biggest bottleneck first. Connect the ticketing system; claim the ticket and move it to Doing *before* the loop starts. [Card: Ralph Loops: Build Dumb AI Loops That Ship — Chris Parsons, Cherrypick](https://www.youtube.com/watch?v=2TLXsxkz0zI)
- Five **engineering loops** worth actually running (Codex / Claude Code / Cursor routines): (1) **dependency triage** — daily ~09:00 Dependabot PR review in the cloud; (2) **docs drift monitor**; (3) **release & shipping status**; plus RFC-drift as the next experiment. Do not replace the whole workflow — automate the mundane. Prompt library: damengloria.com/loops; Matthew Berman’s Loop library for catalog reuse. [Card: 5 Engineering Loops I'd Actually Run with Codex](https://www.youtube.com/watch?v=5dHRqb51fs0)
- **Demand-driven context:** do not pre-write the whole KB. Let **agent failure** (wrong/empty context) mint the next context block. Pre-wiring MCP + institutional knowledge was accurate ~10–30% of the time; the rest became human data-entry. Analogy: *Memento* — agents have no durable memory unless you write the gap after it hurts. Enterprise focus should shift from “how good is the agent” to “how good is the context”; a **KBAN board** of knowledge gaps is the predicted operating artifact. [Card: Demand-Driven Context: A Methodology for Coherent Knowledge Bases Through Agent Failure](https://www.youtube.com/watch?v=_QAVExf_1uw)
- **Colleagues beat a bigger model.** One local Qwen 3.6 27B running **eight agents + one isolated ninth**. Supervisor (Emma, chief of staff) delegates because **tool sprawl** fills the context window until the model cannot pick the right tool. Split when an agent needs its own memory/identity: Sage = deep research, Muse = brand/content, Emma keeps calendar (do *not* extract Tempo — a real CoS would not). Model org on real-world job boundaries. [Card: Your AI Assistant Doesn't Need a Bigger Model. It Needs Colleagues](https://www.youtube.com/watch?v=4go2X5If31A)
- RIG OS JAKE is a **governance/execution/memory/quality/command layer**, not a chatbot. Split: Operator → Mission Control → Hermes Conductor → Agent Runtime → tools → Deviation Engines → approval gates → artifact/memory update → skill crystallization. A task is complete only when objective-or-block is documented, artifact exists, evidence captured, approvals recorded, gates run, run log complete, result packet returned, skill candidate evaluated, next action stated. Threshold ladder: **below +3σ blocked**; +3σ proprietary edge; +5σ signature; +8σ frontier; +10σ category creation. Required phases: Anti-Median Frame → Reality Anchor → Mechanism Furnace → Cross-Domain Collision → Mutation → Deviation Scoring → Final Gate. ## Anti-generic deviation engines (the fleet’s quality law)

- **Robust-MAD-Z, not mean-Z.** `RobustMADZ = 0.6745 * (score − median(baseline)) / rawMAD(baseline)` where `rawMAD = median(|xᵢ − median|)`. Equivalent: `scaledMAD = 1.4826 * rawMAD`; `robustZ = (score − median) / scaledMAD`. **Do not multiply by both 0.6745 and 1.4826.** Zero-MAD fallback: `"zero" | "iqr" | "epsilon"`. Raw score = “is it good?”; MAD-Z = “is it unusually good vs the generic center?” Ship only statistically deviant + truth-anchored + mechanistic. ## Game theory, second-order moves, opponent process

- Game theory = decisions whose outcome **depends on others’ choices**. Prisoner’s Dilemma: mutual silence = light sentence; unilateral confess = walk; mutual confess = worse for both. Nash equilibrium = where no one wants to unilaterally change — **not** the globally best outcome (price wars, climate free-riding). Cooperate vs defect is trust vs self-interest. [Card: Game Theory Explained: The Ultimate Guide to Life’s Strategy](https://www.youtube.com/watch?v=eH6UgRPSBE0)
- Dangerously-smart decision rule: play **three plies out** (“what will this move create three steps from now?”). Sequence beats speed. Board awareness first: environment, resources, relationships, weaknesses, opportunities, constraints — a move without the board is guessing. Emotion narrows perception (fear→danger only, anger→offense only, excitement→opportunity only); hold clarity under provocation. Compounding is quiet first. [Card: How to Become Dangerously Smart | The Art of Strategy | Full Audiobook](https://www.youtube.com/watch?v=uzkka_ie6vk)
- “Game of Life” card: treat life/strategy as **iterated play with compounding and optionality**, not a single decisive move (pair with Temporal Horizon Integrity + kill criteria). [Card: You've (Likely) Been Playing The Game of Life Wrong](https://www.youtube.com/watch?v=HBluLfX2F_k)

## Calibration, bias, metacognition, local learning

- Availability bias (weight what’s handy) and confirmation bias (filter contradictions). Science as a **system for interrogating**, not a pile of facts: RCTs, peer review, communal durable knowledge. First combat step: admit the bias is in *your* thinking. [Card: Introduction to Cognitive Bias: Crash Course Scientific Thinking #1](https://www.youtube.com/watch?v=d2r7Bk1NlgU)
- Mental-model kit for under-uncertainty work: **compound interest, feedback loops, probabilistic thinking**; process counters: **red-team analysis and base-rate analysis**. [Card: Train Your Brain to Outsmart Any Situation - Improve Your Critical Thinking Skills | Audiobook](https://www.youtube.com/watch?v=tOFPtiM48qg)
- Metacognition (Fleming): flexibility = know when to stand vs pivot; **update mental models** when evidence requires it; seek feedback and actually listen when it is uncomfortable. [Card: The Secrets of Metacognition](https://www.youtube.com/watch?v=p6P11e32iW4)
- Biological learning ≠ backprop. **Predictive coding**: each layer predicts the layer below; energy = total prediction error; network relaxes to cut that energy. Weight updates resemble **Hebbian** (pre × post activity); local_update = f(local_error, local_activity, local_context) — no frozen forward + exact backward pass. Credit assignment without global autodiff. Active inference: pick the next action that balances **reducing uncertainty** vs preferred outcomes (the same math as Information Gap Score). [Card: The Brain’s Learning Algorithm Isn’t Backpropagation](https://www.youtube.com/watch?v=l-OLgbdZ3kk)
