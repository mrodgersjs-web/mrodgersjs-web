# System Frame — Sales / close path (domain)

## 1. Boundary
- System of interest: qualified conversation → signed work
- Inside: discovery, proposal, follow-up, forecast
- Outside: buyer committee, budget cycle, competitor
- Boundary rationale: do not mix top-of-funnel volume into close-path health

## 2. Stocks
| Stock | Unit | Current | Owner |
|---|---|---|---|
| qualified opps | deals | | Darius / AE |
| proposals out | docs | | Darius |
| stuck >14d | deals | | AE |
| signed | $ | | Mike |
| recorded proof | packets | | studio |

## 3. Flows
qualify → propose → follow-up → sign → proof packet
Leak: no next-step date = silent death

## 4. Actors
| Actor | Wants | Pulls |
|---|---|---|
| Buyer champion | internal win | qualified |
| Economic buyer | risk down | proposals |
| Mike | signed + proof | signed, packets |
| AE | forecast accuracy | stuck |

## 5. Loops
- R2: signed → proof → reputation → easier next close
- B1: discounting to close → price as the product → worse next deal
- B2: Gate-D on send (no freelance send from agents)

## 6. Delays
proposal → decision: 14–45d. Forecast that ignores delay is a lie.

## 7. Archetype suspects
`studio map "pipeline full nothing closing discounting to move deals"`
Typical: Shifting the Burden (discount vs discovery) or Eroding Goals (forecast).

## 8. Leverage
Rank 6: every deal has a next-step date visible to Mike.
Rank 5: no discount without a written concession from the buyer.
Rank 3: goal is signed proof, not "activity."

## 9. Measurement
- Health: signed $ / 30d and proof packets sealed
- Lead: % opps with next-step date
- Falsifier: 30 days, 0 signed, pipeline "full" → this frame is theater

## 10. Corpus
