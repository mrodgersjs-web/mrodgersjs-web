# Workflow — Find Leverage

Use after a frame or diagnosis exists: choosing WHERE to intervene.

1. Run `studio leverage` and walk ranks 12 → 1 against the framed system.
2. Mark where every EXISTING intervention sits. Most orgs discover they
   live at rank 12 (parameters) and argue there because it is cheapest.
3. For each rank one step above the current answer, write the concrete
   intervention that rank implies (question field in the data guides it):
   - 11 buffers: what stock gets slack?
   - 10 structure: what routing/accumulation changes?
   - 9 delays: which feedback gets faster, or which action gets slower?
   - 8/7 loop strength: which error signal strengthens, which gain gets governed?
   - 6 information: who causes a consequence they never SEE — make them see it?
   - 5 rules: which rule changes everyone's rational strategy at once?
   - 3 goals: what single variable is the machine actually optimizing?
   - 2 paradigm: what must everyone believe for this system to make sense?
4. Choose the HIGHEST rank you have authority for, not the highest that
   exists. Record the authority constraint — it is itself diagnostic
   (who owns the goal? = leverage rank 3 material).
5. Cost the one-rank-higher option explicitly even when rejected.
6. Corpus check: `studio search "leverage points <domain>"` — Meadows'
   essay and derivatives are in the KB; cite the card.
7. Output: chosen intervention + rank + rejected higher option + why +
   the falsifier that would prove the rank choice wrong.
