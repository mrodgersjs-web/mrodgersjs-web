# Automate Google LSA Leads w/GHL Ai Agents!

Jarid Orgeron demonstrates how to build and deploy a GoHighLevel AI voice receptionist that answers missed Google Local Service Ads calls 24/7, preserves ad ranking, captures lead details, and creates a recurring agency revenue stream.

## Procedure / models distilled
- Prioritize LSA responsiveness: Google ranks Local Service Ads primarily by how quickly and consistently businesses answer calls and messages; missed calls or slow replies can stop ads from showing.
- Position a 24/7 GHL AI voice agent as a backup receptionist that catches calls only after the business line rings and is missed, not as a wholesale replacement for live staff.
- In GHL, navigate to AI agents > Voice AI > Create custom agent to configure inbound voice automation inside one interface.
- Select a capable LLM (Claude 4.5 Sonnet recommended) and a natural voice (e.g., Jessica); optimize conversation flow and speed-to-resolution over human-likeness.
- Program the agent prompt around four phases: a brief opening, discovery/qualification questions, contact information capture, and a closeout that confirms next steps and future-paces the outcome.
- Disclose the agent as a "virtual assistant" immediately and give callers an easy phrase to reach a live person.
- Train the agent by creating a knowledge base with the web crawler on the client’s website; add FAQs, documents, or tables to handle services and details accurately.
- Fine-tune call behavior with timezone, max call duration, idle silence handling, and dynamic voice speed; leave default system prompts unchanged unless there is a specific reason.
- Configure post-call notifications (email/SMS) and optionally trigger GHL workflows so the business receives transcripts and summaries for follow-up.
- Purchase an internal GHL number, then set the business carrier’s conditional call forwarding so missed calls route to the AI instead of voicemail, while still giving live staff the first chance to answer.
- Set the agent to answer 24/7 and disable the "AI agent as backup to the phone number" toggle when calls are already conditionally forwarded; enable it only if the GHL number is the primary line used with the mobile app.
- Test the agent via web call or cell before deploying to ensure it qualifies leads, captures details, and closes properly.
- Use the provided prompt library as a starting template, then paste it into ChatGPT/Claude to adapt company names, staff names, and industry-specific details.
- Package the AI receptionist as a monthly add-on ($200–$1,000) tied to the revenue it generates for the client.

## Failure modes named
- Trying to hide that the agent is AI instead of disclosing it as a "virtual assistant" upfront.
- Wasting effort chasing perfect human-sounding voice rather than useful conversation flow and fast answers.
- Building old-school "press 1, press 2" IVR logic rather than a natural, goal-oriented dialogue.
- Opening the call by demanding contact info, which increases hang-ups.
- Missing or slowly responding to LSA calls/messages, which directly lowers ad rank.
- Editing default system prompts without knowing what they control.
- Treating the AI as a total replacement for humans instead of a missed-call safety net.
- Failing to customize names and details in the prompt, confusing the caller.
- Misconfiguring call forwarding or the "AI backup" toggle so callers get extra rings or voicemail.
- Taking on a business without a website for the web crawler without offering to build one.
