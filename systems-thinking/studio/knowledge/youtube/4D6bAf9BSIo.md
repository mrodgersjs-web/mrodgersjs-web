# GitHub Trending Today #33: chromex, whatcable, link-cli, open-slide, serve-sim, baguette, TagTinker

A rapid-fire catalog of 35 trending open-source projects, grouped around practical patterns for AI-agent tooling, browser and mobile automation, local-first interfaces, and developer productivity.

## Procedure / models distilled
- Run a browser sidepanel assistant through a local native bridge so it can read the active page, summarize tabs, process screenshots and voice, while keeping API credentials out of extension storage.
- Inspect a plugged-in USB-C cable's hardware metadata via a system menu-bar app to report charging wattage, data speed, and display support in plain English.
- Issue one-time virtual payment credentials from a Stripe wallet for autonomous agents, with each spend gated by a phone push-notification approval.
- Build presentation decks as pure React components on a fixed 1920×1080 canvas so coding agents can generate slides without learning a slide DSL.
- Stream a booted iOS simulator screen as a high-frame-rate MJPEG feed to a web UI so AI agents can see and interact with mobile apps without opening Xcode.
- Control headless iOS simulators with a lightweight Swift CLI that boots devices, streams screens at 60 FPS, and injects multi-touch gestures through a localhost web UI.
- Inject a curated AI-coding glossary directly into the LLM context window to reduce jargon hallucination and enforce shared terminology.
- Build a complete autonomous coding agent in ~400 lines of portable shell (Bash, cURL, awk) with an interactive loop and file-editing tools, avoiding heavy language runtimes.
- Coordinate specialized sub-agents to reverse-engineer undocumented legacy code into traceable specifications, C4 diagrams, and API contracts.
- Swap the model backend of an agent CLI while preserving the exact user experience, tool loop, and file-edit behavior to slash API costs.
- Compile raw PDFs and Markdown into a permanent interlinked wiki using tree-based indexing instead of vector retrieval, supporting arbitrarily large documents.
- Embed an MCP server in a lightweight database client so local agents can query live MySQL, Postgres, SQLite, Redis, DuckDB, and MongoDB with natural language.
- Let an AI model read operational runbooks and autonomously execute mitigation steps when infrastructure alerts fire.
- Package an AI coding agent as a portable, zero-install folder that leaves no trace on a host after the USB drive is unplugged.
- Crawl public documentation sites into clean, locally saved Markdown files so agents get pure text context instead of noisy HTML.

## Failure modes named
- Constant tab-switching between the browser and an AI assistant breaks flow.
- Identical-looking USB-C cables can deliver 5 W or 100 W, with or without Thunderbolt/data/display support.
- Giving autonomous agents a real credit card creates catastrophic financial risk.
- Slide DSLs and clunky presentation tools force agents to wrestle with syntax instead of content.
- Heavy Electron apps are overkill for simple reading tasks like Markdown previews.
- Confusing AI-coding buzzwords make LLMs hallucinate definitions and misuse terminology.
- Running Claude Code continuously on Anthropic's API is prohibitively expensive.
- Undocumented legacy codebases hide architecture, data flow, and API contracts.
- Scraping docs as raw HTML floods LLM context with garbage and wastes tokens.
- Strict corporate firewalls and deep-packet inspection block traditional VPN traffic.
- Manual incident runbook execution is stressful, slow, and error-prone.
- Vendor lock-in for AI coding assistants limits model choice and design freedom.
