# 35 Claude Code skills on GitHub: claude-video, WRITING.md, paper2code, skill-doctor, skills-manage

The video is a rapid tour of 35 open-source Claude Code skills trending on GitHub, each packaging a narrow instruction set or workflow that changes what the agent can do, how it writes, and how it interfaces with code, media, research, and other tools.

## Procedure / models distilled
- Make video watchable for Claude by installing a skill that downloads the file, extracts auto-scaled frames, pulls the timestamp transcript, and feeds frames plus audio transcript to the agent.
- Control prose quality with a single `WRITING.md` rule file in the project root that bans filler words and enforces concise, senior-developer voice.
- Generate premium UIs by loading a focused skill pack that teaches the agent Framer Motion, glassmorphism, and Apple-style scroll effects instead of default identical layouts.
- Convert research papers into executable PyTorch by passing a PDF to a skill that extracts methodology and math and emits heavily commented code.
- Curate production-ready skills instead of writing prompts from scratch, selecting domain skills such as strict RAG retrieval windows, structured image prompts, or Anthropic-aligned design rules.
- Capture personal voice in a persistent file by having a voice-builder skill interview you, then use that voice to generate content matrices, grade drafts, and create infographics/thumbnails.
- Keep agent instructions small, sharp, and single-purpose; use a `language.md` controlled-vocabulary file with strict synonym warnings so the agent acts as a precision tool rather than a chatbot.
- Inject real brand context by dropping in a `design.md` extracted from a major company design system, so the agent scaffolds components with the right mood and pixel constraints.
- Audit your skill directory locally with a skill-doctor tool that scans for overlapping prompts, conflicting priorities, and security risks, then prioritizes fixes to prevent hallucination.
- Centralize skill distribution with a Tauri desktop app that stores skills once and symlinks them into Claude Code, Cursor, Gemini CLI, Code Act, and 23 other platforms, with import and discovery helpers.
- Turn Claude Code into a persistent automation layer by loading an opinionated 3M (mindset, method, machine) starter kit that audits tasks, manages routines, and runs background operations.
- Run autonomous technical-debt audits by detecting the stack and invoking the right static-analysis tools, then scoring code across nine dimensions and persisting a citable `audit.md`.
- Stabilize AI-generated sprite sheets by normalizing backgrounds, removing artifacts, and mathematically aligning frames to eliminate flicker, jitter, and size changes before export to Unity or Godot.
- Keep library agents on current APIs by installing official skills embedded in NPM/Python packages and symlinking them to `.claude/skills`, version-locked to installed dependencies.
- Force spec-first web design by having the agent generate a nine-section `design.md` covering typography, motion, layout, color, and accessibility, then write HTML/CSS/JS that self-audits against a 100-point checklist.
- Adopt disciplined engineering prose with a drop-in technical-writing rule set distilled from Strunk & White, Orwell, and Pinker that strips hedging, filler words, and the curse of knowledge.

## Failure modes named
- AI cannot watch videos or hear audio by default, so video context is inaccessible.
- AI-written documentation is immediately recognizable because it overuses clichés like “delve into,” “crucial,” and “in conclusion.”
- Default Claude Code UIs converge on identical generic designs.
- Reading a paper and implementing it are separate problems; the gap causes research to stay theoretical.
- Most agent prompts are kitchen-sink files that give the AI too much room to overthink.
- Using multiple agents (Claude Code, Cursor, Gemini CLI, Code Act) leads to messy, unsynced rules.
- Overlapping or conflicting skills confuse the agent and increase hallucination risk.
- Agents hallucinate deprecated library APIs because training data lags behind new releases.
- Agents add unnecessary abstractions and perform unsolicited refactors.
- Hitting a rate limit mid-refactor can destroy all context.
- Models from the same family share the same blind spots, so a single agent can silently fail without a cross-model check.
- Agents waste tokens rereading conversation history rather than generating code.
