# How Canva uses 'growth loops' to move customers from freemium to paid

Canva converts free users to Pro by embedding premium content and high-utility paid features inside a genuinely valuable free product, then letting users self-discover the subscription math rather than forcing upgrades through restrictions.

## Procedure / models distilled
- Freemium-first mission alignment: make the free product independently useful so users can design regardless of budget, not a crippled teaser.
- Avoid tactical friction: don't cap usage, interrupt with ads, or gate core actions to pressure upgrades.
- Pro adds new value rather than unlocking restricted value: paid features should introduce capabilities free users never had.
- Premium content loop: free users search for and place premium assets while designing, then face a pay-per-use or subscribe choice at download.
- Math-based conversion trigger: show that unlimited access plus the content library costs less than accumulated $1-per-asset purchases.
- Unlimited usage as conversion enabler: remove download limits so the subscription becomes an obvious value multiplier once premium assets are adopted.
- Jobs-to-be-done feature design: identify high-value user jobs and build flagship Pro features around them (brand consistency, multi-platform resizing, animation/video).
- Brand Kit for brand consistency: centralize logos, fonts, and colors so users can apply them quickly and stay on-brand.
- Magic Resize for distribution: design once and auto-resize for multiple social channels (LinkedIn, Twitter, Pinterest, Instagram).
- Feature tier migration: move mature capabilities (e.g., animation/video) down to free over time as they become core to the mission, while building new Pro capabilities above.
- User research as input loop: validate which jobs users care about most before launching paid features.

## Failure modes named
- Relying on tactical friction (usage caps, ads, paywalls on basic actions) as the default freemium playbook.
- Treating Pro as an unlock key for artificially restricted free value instead of a genuine value add.
- Degrading the free experience so much that it conflicts with a mission of accessibility.
