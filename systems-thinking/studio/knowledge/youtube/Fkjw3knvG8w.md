# Claude Code Just Changed the Meta Ads Forever

The video demonstrates a Claude Code–powered workflow that diagnoses why Meta ads fail, builds a structured ad strategy with domain skills, and generates professional image and video ad assets using VS Code and Pencil.dev.

## Procedure / models distilled
- Start from a structured prompt template that captures niche, product, audience, offer, and ad platform so Claude Code produces an aligned strategy.
- Run the workflow inside Claude Code within VS Code, trusting the workspace so the agent can write files and manage project context.
- Install and invoke marketing skills from the Claude Code marketplace so the agent applies domain-specific paid-ads reasoning.
- Diagnose ad failures first by auditing targeting, creative, and strategy before generating any assets.
- Use Claude Code to generate a full Meta ad strategy: ad sets, interest stacks, hooks, budget allocation, and copy.
- Persist project context with `agent.md`, `Claude.md`, and `system.md` files so the session can be resumed without re-explaining everything.
- Organize outputs into a folder structure that separates image scripts, video/UGC scripts, and other formats for clean handoff.
- Generate shareable image-ad scripts with hooks, primary text, headlines, and design briefs before producing visuals.
- Connect Pencil.dev, an open-source Canva alternative inside VS Code, to Claude Code for free in-context image generation and editing.
- Iterate ads in place by asking Claude Code to update themes, copy, or layout and regenerate images via Pencil.
- Produce UGC-style video scripts and hooks that can be passed to media, voice, or video-generation agents.
- Optionally plug in image-generation APIs or voice/video agents when native output quality is insufficient.

## Failure modes named
- Wrong targeting, broad keywords, and wasted budget.
- Poor creative with no clear value proposition or reason to click.
- Launching without goals, tracking, or optimization.
- Copy full of jargon and vague promises instead of concrete outcomes.
- Targeting the curious rather than the motivated buyer.
- Messaging that targets fear instead of aspiration.
- Losing project context across disconnected tools or sessions.
- Accepting first-draft image quality instead of refining theme and copy.
