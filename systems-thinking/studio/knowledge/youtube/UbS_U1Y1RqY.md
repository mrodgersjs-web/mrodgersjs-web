# Systeme.io Funnel Tutorial ✅ Lead Gen Funnel Step-by-Step + FREE Template

Phil builds a complete lead generation funnel in Systeme.io from scratch: a landing page, thank-you page, automated email campaign, and an automation rule that ties them together.

## Procedure / models distilled
- Set up a custom domain and custom email address in Systeme.io before building the funnel so the pages and emails look legitimate.
- Create a new sales funnel, choose the "Custom" type to avoid pre-built template bloat, and set the URL path to match the lead magnet name.
- Build the opt-in page with a two-column layout: outcome-driven headline, supporting text, name/email form fields, action-oriented button, and a lead magnet image.
- Set global default typography first—e.g., a Google Font like Poppins—so you don’t have to style every heading and text module individually.
- Center-align columns, choose a medium content width, and add top/bottom padding so the page fills the screen instead of bunching at the top.
- Write the headline around a result or outcome; ask for the "best email address" to nudge users toward their primary inbox; make the submit button full-width and specific.
- Generate the lead magnet cover image with AI, convert it into a book mockup in Canva, then upload the mockup to the opt-in page and resize it.
- Save the opt-in page as a reusable master block so the thank-you page can reuse the same header/footer and branding.
- Design the thank-you page as a single-column confirmation: a success message, the lead magnet image, and instructions to check the inbox and junk folder.
- Create the delivery email in the classic editor using plain text to reduce spam risk; personalize the subject and body with the subscriber’s first name.
- Deliver the resource by linking to a hosted file instead of attaching it directly, which keeps emails light and fast.
- Connect the funnel to the email campaign with an automation rule: trigger "funnel step form subscribed," action "subscribe to campaign," and tag the contact to track the source.
- Test the entire flow end-to-end by submitting a real email through the live funnel and confirming the thank-you page and email arrive.

## Failure modes named
- Pre-built funnel templates add unnecessary bloat; starting from a custom blank page is cleaner and faster.
- Delivering the lead magnet directly on the thank-you page lets people submit fake emails, weakening the list.
- Heavy visual-editor code in emails can hurt deliverability; plain-text/classic-editor emails are less likely to be flagged.
- Attaching the lead magnet file directly makes emails heavier and slower to load; a hosted link avoids this.
- Forgetting to set default typography before styling individual modules creates rework and inconsistent fonts.
- New Systeme.io accounts require manual email-sending approval at first, so initial automated emails may be slightly delayed.
