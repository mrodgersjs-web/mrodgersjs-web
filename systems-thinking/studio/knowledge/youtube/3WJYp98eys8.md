# Study Strategies: Spaced Practice

Spaced practice outperforms cramming because distributing the same total study time over longer intervals forces retrieval and relearning, which strengthens long-term memory.

## Procedure / models distilled
- Schedule the same total study hours across multiple days or weeks rather than in one session before an exam.
- After each class, take a break to unwind, then review the day's material later that same day.
- For a Mon/Wed/Fri class schedule, briefly review each class later that day, then hold brief study sessions on Tuesday, Thursday, and Sunday; take Saturday off.
- Treat the forgetting that occurs between sessions as desirable difficulty: the act of remembering and relearning information again deepens encoding.
- Protect sleep by avoiding late-night cramming, because sleep supports memory consolidation and learning.
- Use short, distributed review sessions instead of one massed session to increase what is retained and slow forgetting.

## Failure modes named
- Cramming: massing all study time the night before an exam produces short-lived learning and rapid forgetting.
- Replacing sleep with study: all-nighters sacrifice the sleep that is needed for memory consolidation.
- Misinterpreting inter-session forgetting as failure: spaced practice feels harder because some forgetting is normal, but that difficulty is the mechanism that improves retention.
