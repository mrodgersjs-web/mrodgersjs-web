# 🔥 STOP Paying for Notion! The BEST Free Alternative (Tolaria + GitHub)

A demonstration of Tolaria, a free Notion alternative that uses a GitHub repository as the backend for markdown notes while integrating local AI agents to query and manage the knowledge base.

## Procedure / models distilled
- Use Tolaria as a lightweight, free alternative to Notion or Obsidian for maintaining markdown-based notes.
- Connect the app to a GitHub repository so every note is versioned and backed up as a file in that repo.
- Configure sync behavior in settings, including sync interval, idle time, and the target GitHub repo.
- Write notes in the Tolaria editor and let the app automatically commit changes to the linked GitHub repo.
- Treat the GitHub-backed vault as a structured knowledge base that local AI agents can read and reason over.
- Switch between detected local AI agents (e.g., Open Code, Claude, Gemini) directly from the app interface.
- Install skills and MCPs, then organize agents inside the app to extend what the AI can do with your notes.
- Ask an AI agent to inspect the latest updated files in the vault and summarize or act on them.
- Prefer cloud persistence through GitHub rather than keeping notes only in local storage.
- Adjust vault context, file naming, PDF handling, and unsupported-file behavior in settings to control how notes are stored.

## Failure modes named
- Treating Tolaria as a one-size-fits-all Notion replacement when the speaker explicitly notes it may not be perfect for everyone.
- Keeping notes only locally instead of syncing to GitHub, which the speaker says is not recommended; cloud sync is the safer pattern.
