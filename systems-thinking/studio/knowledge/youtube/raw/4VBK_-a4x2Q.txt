hi I'm Jason Collins and this video is
an introduction to prospect theory
prospect theory is a descriptive theory
of decision making under risk it was
developed by Daniel Kahneman and Amos
diversky as a challenge to expected
utility Theory
prospect theory as the following
features
first it has a value function that is a
function that describes a value to each
possible outcome
the value function incorporates
reference dependence loss aversion and
the reflection effect
reference dependence means that the
value of an outcome is judged relative
to a reference point
loss aversion means that the value of a
loss is greater than the value of an
equivalent gain
the reflection effect means that agents
are risk averse in the gain domain and
risk seeking in the Lost domain
prospect theory also has a probability
weighting function whereby objective
probabilities are subjectively weighted
by the agent
small probabilities are weighted
relatively more heavily than moderate
probabilities
those weights are then applied to the
value of each outcome
prospect theory is an as if model of
decision making people do not perform
the calculations implicit in the
application of prospect theory rather
they act as if they are performing those
calculations that makes prospect theory
a descriptive Theory not a theory of how
people actually make decisions
the following videos break down each of
the elements of prospect theory and
explain how they are Incorporated in its
implementation
