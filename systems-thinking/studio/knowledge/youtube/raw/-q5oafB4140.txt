In the next few classes, I'll be discussing

What I mean by this is that
MBAs have particular advantages,
particular reasons, that will help us accomplish

Essentially, there are eight tasks, eight uses of
MBAs.
I'll talk about these in turn,
but essentially they are: descriptions,
explanations, experimentation, analogy
or analogical thinking, education and
communication, the development of a
cornerstone or focal object,
thought experiments, and predictions.
Description: An MBA is essentially an
attempt to describe a real-world system,
or in some cases, an
artificial system. It's a
simplified description, but it's still a
description of that system
in some sense. An MBA is similar to a
model text, a model that one can
write down what's happening around
us.
It's important to note that models that
aren't simple aren't useful, and in fact, there's
a great story by Borges, in a tale
called "On Exactitude in Science," where he
describes a geographer trying to
construct a map that's an
exact copy of the real world.
But if we think about it, a  A map that is
exactly like the real world, that
includes every detail of the real world,
is not useful, because to use it
we must travel through the real world.
So in this context, models that
are not simple, that are not simple
representations of the real world, are not
useful to us.
And of course, Albert Einstein is sometimes
paraphrased when he said, "Make your model
as simple as possible, but not
simpler."
Incidentally, this quote is in some
sense a model; he never said
those exact words, but he said something very similar
many times, as far as I know.
But that is the basic idea: one wants to
build the model as a
simple description of real-world phenomena. Model-based approaches
are sometimes used as
explanations of the underlying phenomena
that control a system.
We can think of this as a proof of concept:
if I have an idea of ​​how a system might work,
then I can build a model
that simplifies it and see if it is possible to create
the same phenomenon, the same level of
aggregation of the phenomenon, that I observe,
based on those principles.
In other words, they illuminate the power of
emergence; they
allow us to encode some simple rules,
run them, and see if...  We obtain the

MBAs can be used for
experimentation.
MBAs can be run
repeatedly under slightly
different conditions to observe changes in
the results.
This is different from other ways of
doing science.  In
other forms of science, one can either run
every possible experiment
or observe all the
possible conditions under which we
want to collect data;
MBAs allow us to look through
all these cases and see what the
results are.  We can change the model
and see what happens next,
and eventually we can observe the resulting
set of outcomes—
something we can't observe in the
real world. Then we can return to the real world
and try to validate all these
experiments.
