Now, we want to use Excel to draw
and analyze error trees.  We will work on an
Excel template for project safety failure
using "AND" gates, "OR" gates,
base events, intermediate events, and top event
... You can follow along by getting the
Excel workbook via
the link provided in the description below ↓ Let's
focus on a site incident scenario with
three causes of failure, including falls
from heights, contact with hazardous materials
, and collision accidents.  We can follow
just four simple steps in Excel to perform
error analysis for
our risk management example, based on ISO 31000,
which is the international standard
for risk management... The first step is to create
logical gateway templates.  Let's start by analyzing the
spreadsheet account provided
for three intermediate events, the
first of which is a fall from heights. The
"AND" gateway provides the logical reasoning
that means a fall from heights occurs
if there is unsafe scaffolding, no
safety net has been installed, and the workers do not have
fall protection braids!  We have once again used the
"and" gateway
to connect to hazardous materials, which means that this occurs in the event of
asbestos exposure, a poor asbestos management plan, and poor
air quality monitoring!  Gate “W” itself provides the
logical reasoning for a hit by accident,
which means that it occurs if workers enter
restricted areas, the site is crowded, and
heavy machinery operators make
mistakes!  The "O" gate links the three
intermediate events to the overarching event,
meaning that we will experience an incident on-site if there is a
fall from a height,
contact with hazardous materials, or an
accident!  We are now able to create
logical gates.  From the "Insert" menu,
select "Shapes" and in Flowchart Shapes,
choose a shape similar to AND,
double-click the shape and type "AND" and
then rotate it by 90 degrees.  Right-click the following and
from the menu, select "Format Shape".  Within the
text options, select the third tab, which is
"Text Box".  For text direction, select
Rotate the entire text 90 degrees or
270 degrees.  We can change the color as
appropriate and create duplicate copies of the
"AND" gate.  As you can see, we can follow the
same procedure to create an "OR" gateway.  This
concludes the first step in conducting
error tree analysis (FTA) using Excel...
Step 2 is to create dynamic templates for
upper and middle events!  Let's start with the
top event and insert a
rectangle from the Shapes list.  Instead of
writing an inline label, we can create a
dynamic template by linking it to
tabular data, which is great for
future updates to assess project risks using a
fault tree!  Left-click on the shape and
in the "Formula Bar", type the equals sign,
then select the top event cell, which is the
location incident, and press "Enter".  After that
we can change the color as appropriate
and start creating
intermediate events... Again, left-click on the shape and
in the "Formula Bar" type the equal sign,
then select the intermediate event cell
that falls from heights and press the
Enter button.  We can change the color as
needed and create the
other two intermediate events, namely
hazardous material contact and collision incidents.
Now we can build the upper section of our tree
by connecting the components!  First, we
connect the top event to the "OR" gate by
entering a line from the shape menu,
and then we connect the three intermediate events
using "elbow connectors" within the
shape menu.  You can select all the items
and "group" them together easily for
transport and placement!  Now we have finished the
second step in performing an
error tree analysis or FTA using Excel.
Step 3 is to create
dynamic templates for the base events and complete the
error tree... Let's start with the base event
and insert a circle from the
Shapes list.  Left-click on the shape and in the
"Formula Bar", type the equals sign, then
select the primary event cell, which is an
unsafe scaffold, and press the Enter key.  After that
and repeat the procedure
for the other eight basic events... Now we can build the
lower section of our tree by linking
the components.  We first link
intermediate events to "and" gates by inserting lines
from the Shapes list.  Then we link each
gate "and" to three key events using
"elbow connectors" within the Shapes menu.
You can again select all the elements and group them
together for easy transfer
and placement in project risk reports.
This completes step three of
conducting a fault tree analysis or FTA
using Excel... Step 4 is to calculate
the probability of the average and highest-order events
!  We have so far completed the
visual risk analysis and assessment
by building a fault tree.  Now we can
focus on the quantitative assessment of risk by
calculating the probability of
intermediate events.  Falls from heights are associated
with three basic events using "AND" gates.  Therefore, the
possibilities should be multiplied.  Click
on the relevant cell and press the
equals sign.  Then use the "product function" to double
the probability of having unsafe scaffolding,
no safety net, and no
fall protection belt.  The same procedure is followed
to find the probabilities of
other intermediate events, namely
contact with hazardous materials and exposure to accidents, and
finally we can calculate the probability of the
highest event!
Site incidents that occur are linked to three
intermediate events using an "OR" gateway.  Therefore,
the possibilities must be combined;
click on the relevant cell and press the
equals sign.  Then use the "sum function" to add up
the probabilities of falling from
heights, contact with hazardous materials,
and injury in an accident.  A probability of
0.0002 indicates that in every 10,000 locations there
will be two accidents!  This
concludes the fourth step in performing an
error tree analysis or FTA using Excel.  The
beauty of
this risk analysis technique is that we can easily make a decision
about countermeasures or
plans to address project risks.  "Zero harm" is a principle
in safety management that aims to
achieve the elimination of all
workplace injury and damage incidents.
Considering the base events of our tree
, we can add other safety controls to reduce
the probability of
intermediate events, which is the product of the
base event probabilities... This will
reduce the probability of the highest event,
which is the sum of the
intermediate event probabilities.  Fault trees facilitate
root cause analysis by tracing back from the
top event to its underlying causes.  By
identifying the root causes of failure,
project managers can implement
targeted corrective actions to prevent
future on-site incidents, and
that's exactly what they do!  An easy solution for
causing consequences modeling, using
just four simple steps in Microsoft Excel.
