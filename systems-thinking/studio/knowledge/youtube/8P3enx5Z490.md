# Google Gemma 4 Browser Agent: Free Chrome Automation Agent Runs Locally (No API Key)

The video explains how the Transformers.js Gemma 4 Browser Assistant is a fully local Chrome extension that runs quantized Gemma 4 E2B and MiniLM models via WebGPU to perform tab management, page summarization, semantic history search, and website interaction without API keys or network calls.

## Procedure / models distilled
- Architect the extension around three Chrome Manifest V3 layers: a background service worker that hosts the models and runs the agent loop, a side-panel chat UI, and a per-page content script that handles DOM extraction and highlighting.
- Use Gemma 4 E2B as the reasoning engine: a 2B effective-parameter model with per-layer embeddings, 128k context, native function calling, and 35+ language support, quantized to Q4F16 for consumer GPUs.
- Use MiniLM-L6-V2 as a tiny local embedding model to turn page text and history into semantic vectors for meaning-based search.
- Download the ~3 GB model files once and cache them in the browser's IndexedDB so the extension works offline and never sends data to a model server.
- Build a tool-calling normalization layer called WebMCP, where every tool exposes a name, description, input schema, and execute function; the model emits a tool-call token block and loops until done.
- Implement tab-management tools (list open tabs, switch to a tab, open a URL in foreground or background, close tabs) so navigation can be driven by natural language.
- Implement website-interaction tools such as ask website and highlight element, using the content script to extract headings, paragraphs, and lists and run retrieval-augmented generation on the current page.
- Maintain a local vector database of browsing history in IndexedDB, indexing title, description, URL, and page content so searches are semantic rather than keyword-based.
- Rely on transformers.js, the JavaScript port of Hugging Face Transformers, with WebGPU acceleration for GPU inference inside the browser.
- Install from the Chrome Web Store or clone the GitHub repo, run `pnpm install` and `pnpm run dev`, and load the extension unpacked for customization or adding new tools.
- Extend the same local-agent architecture into per-tab agents, options pages, or popup-based assistants.

## Failure modes named
- Cloud-based browser assistants send every page and history query to a remote server, exposing private browsing data and usually moving behind a paywall as costs rise.
- Cloud assistants stop working the moment the network drops.
- Standard browser history search only matches keywords in titles and URLs, so it fails when you cannot remember the exact wording.
- Pasting internal company pages, banking sites, or other sensitive content into cloud chat tools leaks private data outside the machine.
- Older laptops without WebGPU support or with integrated graphics can fall to roughly five tokens per second, making the agent feel sluggish.
- The extension does not bundle the model, so the first use requires a multi-gigabyte download before anything works.
