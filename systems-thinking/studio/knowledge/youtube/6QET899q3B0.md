# Introduction to Agent-Based Modeling: Modeling Basics with Paul Smaldino

Paul Smaldino introduces agent-based modeling as a complementary, deliberately simplified approach to studying complex systems, contrasting it with equation-based models and demonstrating how local rules generate emergent phenomena like flocking and epidemic curves.

## Procedure / models distilled
- Treat scientific modeling as a deliberate simplification: distinguish essential relationships from inessential detail so reality becomes surveyable and tractable.
- Build an agent-based model by representing individuals as explicit computational entities that can carry heterogeneous properties, locations, social ties, rules, and knowledge.
- Generate flocking, schooling, or swarming with three local rules: separation to avoid collisions, alignment to match neighbors’ direction, and cohesion to stay near the group.
- Use bounded, local perception rather than global coordination; each agent reacts only to nearby neighbors, producing large-scale order without central control.
- Add calibrated noise or jitter to agent behavior so movement looks organic rather than artificially smooth.
- Choose agent-based modeling when the system requires explicit heterogeneity, spatial or network structure, or when the phenomenon of interest is emergent and analytically intractable.
- Pair equation-based models with agent-based models as complementary tools; equations capture aggregate dynamics, while ABM reveals individual-level mechanisms that produce them.
- Operationalize “flatten the curve” in an epidemic ABM by slowing agent movement or reducing new contacts, showing the same aggregate effect can arise from behavior rather than pathogen biology.
- Use spatial proximity plus random-walk movement as a minimal mechanism for contact and contagion in social-system models.
- Start with coarse-grain, abstract models to build intuition and baseline dynamics, then refine toward fine-grain parameterization only when precise empirical data justifies it.

## Failure modes named
- Framing agent-based and equation-based modeling as competing approaches rather than complementary lenses.
- Building overly fine-grain, highly detailed models before establishing baseline intuitions with simpler abstract models.
- Treating aggregate parameters like transmissibility as fixed intrinsic properties instead of emergent outcomes of contact structure and behavior.
- Invoking centralized or teleological explanations (e.g., leader birds, psychic powers) for emergent coordination that actually arises from local rules.
- Attempting an unbroken, complete description of reality, which is simultaneously true and useless for science.
