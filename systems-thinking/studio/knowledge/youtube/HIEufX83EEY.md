# The Toyota Production System as Taught by Toyota - Episode 04

This episode explains how Toyota shifted from a push system to a just-in-time pull system, using kanban cards as physical signals that trigger replenishment and production instructions between processes.

## Procedure / models distilled
- Define just-in-time as producing only what is needed, when it is needed, and in the amount needed.
- Contrast push systems, where parts move from a prior process to the next process regardless of actual downstream need.
- Use pull systems so downstream processes withdraw parts from upstream only in the quantities actually required.
- Attach kanban cards to parts or parts boxes as portable production and withdrawal signals.
- Remove the kanban from the box when the first part is consumed, capturing real-time usage.
- Carry the removed kanban to the preceding process to authorize withdrawal of the corresponding part or box.
- Remove a kanban from the retrieved parts and send it upstream as a production instruction.
- Close the kanban loop so each withdrawal generates a replenishment signal, keeping inventory matched to consumption.

## Failure modes named
- Push system: delivering parts from the previous process to the next regardless of actual need, causing overproduction and mismatched inventory.
