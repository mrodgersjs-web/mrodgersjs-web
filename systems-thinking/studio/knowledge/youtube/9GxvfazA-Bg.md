# Hermes: This Free AI SEO Super Agent is Insane

Hermes Agent uses persistent goals and swarm mode to autonomously execute end-to-end SEO workflows including keyword research, content calendars, blog writing, and Netlify deployment.

## Procedure / models distilled
- Install and run Hermes Agent from its free GitHub repo in a terminal.
- Trigger a persistent goal with `/goal` to create an autonomous loop where an AI judge verifies completion across up to 20 turns.
- Give Hermes a single SEO mission, e.g., "write five SEO blog posts about AI automation and save them as files," and let it iterate until the judge accepts the output.
- Generate local markdown deliverables such as competitor gap analysis, content calendar, brief templates, keyword clusters, and site architecture in one autonomous run.
- Plan full website taxonomy in depth: URL structure, category taxonomy, keyword clusters, internal linking depth rules, and navigation.
- Inspect any generated markdown file with a markdown live preview tool before publishing.
- Switch to Hermes Workspace for a richer UI than the terminal and a Kanban board for task queues.
- Enable swarm mode to run multiple Hermes agents in parallel toward one shared SEO mission.
- Build a "swarm office" with specialized agents (e.g., foundation, triage) for repetitive SEO tasks like keyword research and link-building strategy.
- Review swarm output files locally, such as a markdown link-building strategy with target directories, communities, and PR opportunities.
- Connect Hermes to Netlify via a personal access token so it can create and deploy content directly to hosted domains.
- Schedule recurring SEO tasks inside Hermes, e.g., "find five new AI-agent-related keywords each day."
- Use AON UI as a single dashboard to manage multiple AI agents including Hermes and schedule tasks centrally.

## Failure modes named
- Treating ChatGPT/Claude like a chatbot for one-off SEO prompts instead of delegating autonomous loops to an agent.
- Assuming AI SEO is just "write me a blog post" rather than deep planning of taxonomy, internal linking, and URL structure.
- Publishing agent-written markdown without inspecting it through a live preview or reading the files.
- Handing a Netlify personal access token to an autonomous agent without considering the security exposure.
- Interrupting a running goal with Ctrl+C without checking what deliverables the agent has already produced.
