# How to activate a funnel | systeme.io tutorials

This tutorial shows how to reactivate a previously deactivated sales funnel in Systeme.io by switching the funnel list filter to inactive and confirming the activation action.

## Procedure / models distilled
- Open the **Sites** tab in the main menu.
- Select **Sales Funnels** from the submenu.
- Recognize that the default view shows **only active funnels**, so inactive funnels are hidden by default.
- Click the dropdown menu next to the search bar to access filter options.
- Choose **Inactive** from the filter dropdown.
- Click the **Filter** button to load the list of all inactive funnels.
- Locate the specific funnel you want to reactivate in the filtered list.
- Click the **three dots menu** on the right side of the target funnel's row.
- Select **Activate** from the contextual menu that appears.
- Confirm the activation in the popup confirmation window.
- Wait for the success notification at the top of the screen.
- Verify that the funnel is restored and accessible again.

## Failure modes named
- Searching for an inactive funnel while the default **active-only** filter is still applied, making the funnel appear missing.
- Selecting **Inactive** in the dropdown but forgetting to click the **Filter** button, so the inactive list never loads.
- Closing the confirmation popup without clicking **Confirm**, leaving the funnel deactivated.
- Assuming that deactivation settings or status are edited directly instead of using the dedicated **Activate** action.
