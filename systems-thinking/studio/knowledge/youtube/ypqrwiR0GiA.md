# Network Theory (Small World Networks)

Real-world networks combine tight local clusters with sparse long-range hubs, creating "small worlds" where information spreads rapidly across vast systems.

## Procedure / models distilled
- Model any system as a graph of nodes (people, neurons, power stations) and edges (relationships, connections, collaborations).
- Identify close-tie clusters where most members are mutually connected.
- Identify hub nodes that bridge otherwise separate clusters.
- Use high-degree hubs as broadcast points to accelerate diffusion.
- Recognize the small-world signature: high local clustering plus short global path lengths.
- Test a network against small-world properties rather than assuming it is random, regular, or purely centralized.
- Map real-world datasets—social, neural, infrastructural—as graphs to reveal hidden structural similarities.
- Predict how fast an idea or behavior will travel by inspecting both cluster density and hub connectivity.
- Design interventions to route through long-range shortcuts rather than forcing messages through every local tie.
- Treat viral phenomena as evidence that the underlying network has small-world topology.

## Failure modes named
- Assuming diffusion must be either fully local (close-tie village) or fully centralized (hub-and-spoke).
- Relying only on close ties for large-scale spread, which isolates an idea inside its home cluster.
- Ignoring hub nodes when trying to broadcast information across a whole network.
- Treating all networks as random graphs and missing the clustering + shortcut structure that enables fast spread.
