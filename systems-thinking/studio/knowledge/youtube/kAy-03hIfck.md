# Homeostasis and Negative Feedback Loops

Homeostasis is a dynamic equilibrium actively maintained by living systems through negative feedback loops that detect deviations from a set point and trigger responses that return the variable toward its ideal range.

## Procedure / models distilled
- Define homeostasis as a dynamic equilibrium actively regulated to keep a variable at a constant level.
- Map the survival constraint that most organisms survive only within a narrow range of internal conditions.
- Track the body-temperature set point around 98.6°F / 37°C and the lethal risk of prolonged deviation.
- Track the blood-glucose set point around 90–120 mg/dL and the lethal risk of severe hypoglycemia.
- Use barriers such as the cell membrane to maintain an internal environment distinct from the external environment.
- Model any feedback loop as a three-part chain: stimulus → sensor → response.
- Run the negative-feedback loop for overheating: rising core temperature is detected by the hypothalamus, triggering vasodilation and sweating to lower temperature.
- Run the complementary negative-feedback loop for cooling: falling temperature is detected by the hypothalamus, triggering shivering to generate heat and raise temperature.
- Recognize that “negative” feedback means deviation-dampening, not harmful or undesirable.
- Contrast positive feedback, which amplifies deviation and is rare in nature, with examples such as blood clotting and labor contractions.
- Use passive transport such as osmosis and diffusion to move particles down concentration gradients without ATP.
- Use active transport to spend ATP pumping particles against concentration gradients when restoring a set point requires it.

## Failure modes named
- Misinterpreting “negative feedback” as harmful rather than deviation-reducing.
- Prolonged deviation from a set point causing cell, tissue, or organism death.
- Severe hypoglycemia causing coma or death.
- Extreme body temperatures disabling proteins and chemical reactions, risking tissue or organism death.
