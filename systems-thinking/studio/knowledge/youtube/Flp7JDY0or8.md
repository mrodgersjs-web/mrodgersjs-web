# Dynamical Systems And Chaos: Bifurcations: Part I (Differential Equations) Summary

A summary of one-dimensional differential equations, their phase-line geometry, and how smoothly varying a parameter can trigger sudden qualitative changes called bifurcations.

## Procedure / models distilled
- Model limited population growth with the logistic differential equation, where growth slows as the population approaches a carrying capacity.
- Locate equilibria by setting the rate of change to zero, then classify each as a stable attractor or an unstable repeller.
- Interpret the carrying capacity K in the logistic equation as the stable equilibrium the population is drawn toward.
- Distinguish differential equations from iterated functions: time and state are continuous in the former, but advance in discrete jumps in the latter.
- Recognize that one-dimensional, deterministic, continuous differential equations cannot produce cycles or chaos because each state value has exactly one possible derivative.
- Use a phase line as a compact geometric summary of fixed points and the direction of flow between them.
- Extend a model by introducing a control parameter, such as a constant harvest rate h, and observe how equilibria shift as that parameter changes.
- Construct a bifurcation diagram by stacking phase lines for successive parameter values, placing the parameter on the horizontal axis and the state variable on the vertical axis.
- Read a bifurcation diagram as a family of phase lines: each vertical slice reveals the fixed points and their stability at that parameter value.
- Define a bifurcation as a qualitative change in the number or stability of fixed points produced by a smooth change in a parameter.
- Expect that smooth, continuous models can still exhibit discontinuous behavioral jumps when an attractor disappears and the system collapses to another branch.

## Failure modes named
- Confusing the logistic map (iterated, discrete) with the logistic equation (differential, continuous); the same name is used for both depending on context.
- Assuming that well-behaved continuous models always respond smoothly to parameter changes; bifurcations can cause sudden crashes or jumps.
- Misreading bifurcation diagrams by forgetting that each vertical slice is a phase line showing fixed-point stability.
