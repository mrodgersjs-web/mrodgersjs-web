# Combining stock-and-flow, agent-based, and social network methods to model team performance

## Claim

Team performance is decisively shaped by accumulated individual attributes, interactions among individuals, and emergent team structures — each affected by multiple feedback loops at different levels of analysis. No single method captures this; a hybrid combining stock-and-flow models, agent-based models, and social network analysis is advantageous for formal modeling of multi-level phenomena.

## Method

Methodological comparison of SFD, ABM, and SNA along the dimensions each represents (accumulation, interaction, structure), followed by a proof-of-concept hybrid model of team performance integrating all three.

## Studio relevance

- **frame**: the method-selection table for framing multi-level systems: stocks for accumulations, agents for heterogeneous interaction, networks for emergent structure. Use it to decide what kind of model a framed system needs.
- **diagnose**: team-level dysfunctions (knowledge loss, coordination failure) live in the cross-level loops this hybrid exposes.
- **ground**: citable support that hybrid SFD+ABM+SNA is an accepted formal approach, not method-mixing adhocery.
